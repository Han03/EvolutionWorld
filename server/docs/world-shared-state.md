# 世界怪物 & 世界 Boss 状态共享方案（大型网游规模）

> 目标：同一只世界 Boss / 世界怪物，所有玩家看到的是**同一份状态的投影**；服务端是
> 唯一事实源（Authoritative），任何客户端不得独立模拟世界实体产生分歧。在此基础上
> 兼顾**数量规模**（怪物成百上千）与**感知一致性**（Boss 血量/仇恨/技能全区一致）。

---

## 1. 分层架构

```
┌──────────────────────────────────────────────────────────────┐
│ 协议层（二进制帧扩展）                                          │
│  C2S_ATTACK 0x04  玩家攻击世界实体（目标wid + 技能槽）            │
│  S2C_BOSS   0x8B  Boss 全局共享状态（血量/阶段/状态/目标/位置）     │
│  S2C_EVENT  0x87  战斗事件（伤害/死亡/复活/范围技能）              │
└──────────────────────────────────────────────────────────────┘
┌──────────────────────────────────────────────────────────────┐
│ 世界共享层（服务端单线程权威模拟）                                │
│  - 世界怪物：AOI 本地模拟 + 增量同步（复用既有 netcode）           │
│  - 世界 Boss：全局模拟（独立于 AOI 可见性，始终推进状态机）         │
│  - 仇恨表 / 技能冷却 / 阶段 / 复活计时：服务端单点权威              │
└──────────────────────────────────────────────────────────────┘
┌──────────────────────────────────────────────────────────────┐
│ 传播层（每 tick 20Hz）                                         │
│  - Boss 位置/朝向：走 AOI 增量（视野内玩家看到移动）              │
│  - Boss 血量/状态/目标/技能事件：Zone 广播（全区玩家，含视野外）    │
│  - 加入即一致：HELLO 后附当前 Boss 全量状态帧                    │
│  - 状态版本号：仅变化时广播（去重，省带宽）                       │
└──────────────────────────────────────────────────────────────┘
```

## 2. 事实源与状态划分

| 实体 | 模拟 | 状态共享范围 | 一致性策略 |
|---|---|---|---|
| **普通怪物**（千级） | 仅玩家 AOI 内的怪物被模拟（isEntityVisible） | AOI 内玩家 | ENTER/UPDATE/LEAVE + 周期 SNAPSHOT 校准；死亡→本区复活计时 |
| **世界 Boss**（全区唯一） | 全局始终模拟（与玩家是否在场无关） | **全区所有玩家** | 位置走 AOI；血量/阶段/目标/技能走 **Zone 广播**（S2C_BOSS + S2C_EVENT） |
| **玩家** | 服务端权威 + 客户端预测 | AOI 内玩家 | 预测 + 后校验/回退（既有防作弊） |

关键点：
- **Boss 是不可分割的全局实体**：不同区域玩家看到的必须一致，因此不能放进"区域本地模拟"。
- **普通怪物允许区域差异**：不同玩家附近看到的怪物本来就是不同的个体，无需跨区一致。
- **服务端单线程 tick**：所有共享状态在同一线程内串行修改 → 天然串行一致，无并发竞争、无锁。

## 3. Boss 状态机（服务端权威）

```
        ┌─────────────────────────────────────────────┐
        │                                             │
        v                                             │
   ┌─────────┐   进入仇恨(aggro非空)     ┌─────────┐   │
   │  IDLE   │ ──────────────────────► │ ENGAGE  │   │
   │(脱战回血)│ ◄────────────────────── │(选仇恨最高 │   │
   └─────────┘  仇恨清空(脱战/无目标)    │  目标)   │   │
        ▲                             └────┬────┘
        │ hp<=0                             │ 目标在攻击范围 → 普攻/技能
        │                              ┌────▼────┐
        │                              │ ATTACK  │──► 技能(范围AOE) / 普攻
        │                              └────┬────┘
        └───────────────────────────────────┘
   ┌─────────┐  hp<=0
   │  DEAD   │ ◄──────────┐
   │(复活计时) │            │
   └────┬────┘            │
        │ 复活计时到       │
        └─────────────────┘ 重置满血/清仇恨 → IDLE（广播复活）
```
- **仇恨（Hatred）**：`aggro: map<playerWid, hatred>`，玩家造成伤害 → `hatred += 伤害`；
  Boss 攻击某目标 → 该目标仇恨小衰减；仇恨最高且在追击范围内的玩家为当前目标。
- **脱战回血**：IDLE 状态缓慢回血；仇恨清空（目标离线/离开）→ 回 IDLE。
- **阶段（Phase）**：按血量比例切换（如 >60% Phase1 / ≤60% Phase2），可挂载新技能。
- **复活**：死亡 → 广播死亡事件 → 复活计时（默认 30s，环境变量 EW_BOSS_RESPAWN 可覆盖）→
  满血回出生点 → 广播复活事件（AOI 内同时 ENTER）。

## 4. 玩家攻击 → 服务端校验 → 状态共享（数据流）

```
C2S_ATTACK {targetWid, slot}
    │
    ▼
服务端 playerAttack()
    ① 校验：目标存在/可攻击/在攻击范围内(3.2m)/玩家攻击CD(0.5s)
    ② 伤害：基础攻击 ± 随机浮动；暴击(可选)
    ③ 应用：
       - Boss：hp-=dmg → 仇恨+=dmg → 若 hp<=0 → DEAD → 死亡事件
       - 怪物：hp-=dmg → 仇恨=该玩家 → 若 hp<=0 → 死亡 → 复活计时
    ④ 共享广播（全区）：
       - S2C_BOSS（血量/状态/目标变化，版本去重）
       - S2C_EVENT（伤害数字/死亡/复活/技能）
    │
    ▼
所有在线玩家收到同一份状态 → 一致性达成
```

## 5. 协议扩展（二进制，逐位对齐）

| 消息 | 载荷 |
|---|---|
| C2S_ATTACK 0x04 | `u32 targetWid + u8 slot` |
| S2C_BOSS 0x8B | `u32 wid + u8 state + u8 phase + f32 hp + f32 maxHp + i32 targetWid + i32 x + i16 y + i32 z + str name` |
| S2C_EVENT 0x87 | `u8 evtType + u32 wid + u32 b + i32 x + i32 z`（evtType: 1=伤害 2=死亡 3=复活 4=范围技能） |

- S2C_BOSS **仅状态变化时发送**（Boss 维护 dirty 版本号，去重）；玩家加入时强制推送一次（加入即一致）。
- 客户端对 Boss **只插值 + 事件驱动，不做预测**（共享实体预测会破坏一致性）。

## 6. 可扩展性

- **新增技能**：在 Boss 状态机 ATTACK 分支按 phase/计时派发技能 → 广播 S2C_EVENT(4)。
- **新增 Boss**：`config.bossCount` + 固定锚点即可，世界生成自动铺开。
- **跨服/分线**：S2C_BOSS 的"全区广播"语义替换为"线/服内广播"，架构不变。
- **掉落/奖励**：死亡事件已含 killer wid，可挂战利品系统（本阶段未实现）。
- **持久化**：Boss 状态可序列化（本阶段内存态，接口已隔离）。

## 7. 防作弊耦合

- 攻击频率：服务端按 `playerAttackCdSec` 强制冷却，客户端不可伪造伤害。
- 伤害计算：完全服务端，客户端只发意图（目标+槽位），杜绝客户端算血/改数值。
- 位置：Boss 位置仍走 AOI + 服务端物理，客户端仅插值。

## 8. 验证（回归）

```
python3 scripts/ws_smoke_test.py --boss    # Boss 共享状态：双客户端血量一致 + 攻击减血 + 死亡/复活
python3 scripts/ws_smoke_test.py --normal  # 既有回归不受影响
```
